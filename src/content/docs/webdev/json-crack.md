# JSON Crack

**[https://jsoncrack.com](https://jsoncrack.com)**

## Overview

JSON Crack transforms raw JSON, YAML, XML, and other structured data into an interactive node-based graph, making it much easier to navigate deeply nested or unfamiliar data structures than scrolling through raw text.

## What is it?

Paste or upload data and it renders as a pannable, zoomable graph of connected nodes representing objects, arrays, and values — collapsible at any level, with search to jump straight to a specific key or value.

## Why use it?

Deeply nested JSON (API responses, config files, GraphQL payloads) is hard to mentally map from raw text alone. Visualizing it as a graph makes structure and relationships between fields immediately obvious, and collapsing irrelevant branches keeps focus on what matters.

## Basic Usage

Paste JSON/YAML/XML into the editor pane; the graph renders live on the other side, with nodes collapsible and searchable.

## Key Features

- Live graph rendering from JSON, YAML, XML, and more
- Collapsible/expandable nodes for large structures
- Search across keys and values
- Export graph as image
- Also available as a downloadable desktop/VS Code extension version

## Top 5 Use Cases

1. Exploring an unfamiliar or deeply nested API response
2. Debugging a config file's structure visually
3. Explaining a data shape to a teammate via exported graph image
4. Comparing/verifying structure across similar JSON payloads
5. Navigating large GraphQL/REST response bodies quickly

## Competitors

- **Browser DevTools JSON viewer** — built-in and convenient, but tree-only, no graph layout or export.
- **jq (CLI)** — powerful for scripted transformation/filtering, but text-only, no visual graph.

## Pros

- Genuinely clarifying visual for deeply nested data
- Fast, browser-based, no install required for the web version
- Supports multiple input formats beyond just JSON
- Free tier covers most casual use

## Cons

- Very large payloads can get visually overwhelming or slow to render
- Some advanced features (larger file limits, extra export options) are paid
- Graph layout isn't always optimal for extremely wide/flat structures
