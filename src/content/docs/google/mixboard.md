# Mixboard

## Overview
Mixboard is a Google Labs experiment for visual brainstorming — a moodboard-style canvas where you generate, arrange, and remix images with AI instead of starting from a blank page.

## What is it?
An AI-powered visual ideation tool built on Gemini 2.5 Flash and Google's "Nano Banana" image editing model. You start from a text prompt or a template, then add, generate, and edit images on a shared board using natural language.

## Why use it?
- Turns vague ideas ("cozy reading nook", "birthday party theme") into a visual mood board fast, without hunting Pinterest for hours.
- Editing is conversational — describe a change instead of using layer/mask tools.
- Useful as a first pass before handing a concept to a designer or before generating final assets elsewhere.

## Installation (how to access)
No install — it's a hosted web app at [labs.google/mixboard](https://labs.google/mixboard). Public beta, U.S. only as of writing. Sign in with a Google account; no separate signup/waitlist reported, but regional availability may change.

## Basic Usage
1. Start a board from a text prompt or pick a pre-made template.
2. Upload your own images or generate new ones inline.
3. Use natural-language commands to edit the board ("make the walls blue", "add a lamp in the corner").
4. Mixboard can also generate supporting text based on the board's image context.

## Key Features
- Template-based or blank-prompt board starts
- AI image generation via Nano Banana
- Natural-language board editing (no manual layer tools)
- Mixed input: upload your own images alongside generated ones
- Context-aware text generation from board contents

## Top 5 Use Cases
1. Home décor / room layout ideation
2. Event theme and mood boards (weddings, parties)
3. Early-stage product or brand concepting
4. Pinterest-style visual collections for a topic
5. Quick client-facing concept decks before formal design work

## Competitors
- Pinterest (curation, not AI generation)
- Canva (AI-assisted design, more polished output tooling)
- Midjourney / Whisk (image generation, less board-oriented)
- Milanote (moodboarding, no built-in AI generation)

## Pros
- Fast, low-friction way to visualize an idea
- Natural-language editing lowers the skill floor
- Free during beta

## Cons
- Public beta — features, quality, and availability may shift or disappear
- U.S.-only at launch, limiting access
- Not a finishing tool — outputs are exploratory, not production-ready assets
- Uncertain long-term support, as with many Google Labs experiments
