# VisuAlgo

**[https://visualgo.net](https://visualgo.net)**

## Overview

VisuAlgo animates data structures and algorithms step by step, showing exactly how operations, traversals, and transformations execute internally — built originally at the National University of Singapore to help students build correct mental models of algorithm behavior.

## What is it?

A large library of interactive visualizations covering sorting algorithms, trees, graphs, heaps, hashing, dynamic programming, and more. Each visualization steps through the algorithm's execution one operation at a time, with the underlying data structure redrawn at each step so you can see state changes directly instead of inferring them from pseudocode.

## Why use it?

Reading pseudocode or static diagrams for something like AVL tree rotations or Dijkstra's algorithm rarely builds real intuition on the first pass. VisuAlgo's step-through animation makes the algorithm's actual behavior visible, which is far faster for building correct intuition than tracing code by hand.

## Basic Usage

Pick a topic (e.g. "Graph Traversal", "Sorting", "Balanced BST"), input or generate sample data, then step forward/backward through the animated execution using the playback controls.

## Key Features

- Wide coverage: sorting, trees, graphs, heaps, hashing, DP, and more
- Step-by-step animated playback with forward/backward controls
- Some topics include a built-in quiz/training mode
- Multi-language interface support
- Free, no account required for basic use

## Top 5 Use Cases

1. Building intuition for a new algorithm before implementing it
2. Studying for technical interviews / data structures coursework
3. Debugging a mental misunderstanding of how a specific traversal works
4. Teaching algorithms visually in a classroom setting
5. Quick refresher on an algorithm you haven't touched in a while

## Competitors

- **Textbook pseudocode/diagrams** — precise and complete, but static — no step-through animation.
- **Algorithm Visualizer (algorithm-visualizer.org)** — similar animated approach with a different topic set and code-execution tie-in.

## Pros

- Deep, well-curated topic coverage
- Genuinely effective step-through animation for building intuition
- Free and browser-based
- Academic pedigree (NUS-built, widely used in CS coursework)

## Cons

- UI feels dated compared to some newer visualization tools
- Some advanced/training features are gated or slower to navigate
- Visualization-only — doesn't generate runnable code from what you see
