# Excalidraw

**[https://excalidraw.com](https://excalidraw.com)**

## Overview

Excalidraw is a free, collaborative, browser-based whiteboard for sketching system architecture diagrams, flowcharts, and wireframes with a distinctive hand-drawn aesthetic that feels more like a whiteboard sketch than a rigid formal diagram.

## What is it?

A canvas-based drawing tool with shapes, arrows, text, and freehand drawing, all rendered in a signature sketchy/hand-drawn style. Supports real-time multiplayer collaboration via shareable room links, and works fully offline with local-first storage.

## Why use it?

Formal diagramming tools (Lucidchart, draw.io) can feel too polished/rigid for early-stage whiteboarding, where the point is fast iteration rather than a finished deliverable. Excalidraw's hand-drawn look keeps sketches feeling provisional and collaborative, and real-time multiplayer means a team can whiteboard together remotely without a separate video-call screen share.

## Basic Usage

Open the canvas and start drawing shapes/arrows/text directly; click "Share" to generate a room link for real-time collaborators, or export the sketch as PNG/SVG.

## Key Features

- Hand-drawn-style shapes, arrows, and freehand drawing
- Real-time multiplayer collaboration via shareable links
- Local-first storage — works fully offline
- Export to PNG, SVG, or shareable link
- Open source, self-hostable
- Libraries of reusable shape sets (AWS icons, UML, etc.)

## Top 5 Use Cases

1. Sketching system architecture diagrams during design discussions
2. Real-time collaborative whiteboarding for remote teams
3. Quick flowcharts and wireframes during planning
4. Teaching/explaining a concept visually in a meeting
5. Embedding lightweight diagrams into docs or blog posts via export

## Competitors

- **draw.io / Lucidchart** — more formal, precise diagramming with richer shape libraries, but less suited to fast, casual sketching.
- **Miro/FigJam** — broader whiteboarding feature sets (stickies, templates, voting), heavier tools than Excalidraw's focused drawing canvas.

## Pros

- Free and open source
- Genuinely fast, low-friction sketching experience
- Real-time collaboration built in
- Works offline, local-first

## Cons

- Not suited for precise, pixel-perfect diagrams
- Fewer built-in templates/shape libraries than heavier whiteboarding tools
- Hand-drawn style is a specific aesthetic choice, not universally appropriate for formal documentation
