# Hoppscotch

**[https://hoppscotch.io](https://hoppscotch.io)**

## Overview

Hoppscotch is a lightweight, browser-based API testing platform — send REST, GraphQL, WebSocket, and other protocol requests and inspect responses without installing a desktop client like Postman.

## What is it?

A request builder UI covering REST, GraphQL, WebSocket, Server-Sent Events, Socket.IO, and MQTT, with request history, environment variables, collections, and team workspace support. Runs entirely in the browser (with an optional self-hosted or desktop version).

## Why use it?

Desktop API clients like Postman are heavier than many workflows need, and account/sync requirements add friction for quick testing. Hoppscotch runs instantly in a browser tab, is open source, and is significantly lighter while still covering multiple protocols beyond plain REST.

## Basic Usage

Enter a request URL, method, headers, and body, then hit send — response body, headers, and status render immediately below, with request history saved automatically.

## Key Features

- Supports REST, GraphQL, WebSocket, SSE, Socket.IO, MQTT
- Environment variables and collections for organizing requests
- Request history and team workspace support
- Open source, self-hostable
- Browser extension available to bypass CORS restrictions

## Top 5 Use Cases

1. Quick ad-hoc API testing without installing a desktop client
2. Testing GraphQL/WebSocket endpoints alongside REST in one tool
3. Self-hosting an internal API testing tool for a team
4. Sharing request collections across a team via workspaces
5. Debugging real-time protocols (WebSocket, SSE) during development

## Competitors

- **Postman** — larger feature set and ecosystem (mock servers, monitors), but heavier and increasingly cloud-account-gated for full functionality.
- **Insomnia** — similar lightweight desktop-first API client, less multi-protocol breadth than Hoppscotch.
- **curl/httpie (CLI)** — scriptable and fast for quick checks, but no visual response inspection or saved collections.

## Pros

- Free, open source, self-hostable
- Genuinely lightweight — instant browser access, no install
- Broad protocol support beyond REST
- Active development and community

## Cons

- Browser CORS restrictions can block some requests without the companion extension
- Smaller ecosystem/integration surface than Postman
- Some advanced team features require an account/paid tier
