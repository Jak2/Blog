# Carbon

**[https://carbon.now.sh](https://carbon.now.sh)**

## Overview

Carbon generates high-resolution, syntax-highlighted images of code snippets — the tool behind most of the polished "code screenshot" graphics you see in presentations, blog posts, and social media.

## What is it?

Paste code into the editor, pick a language, theme, font, and background style, and export a high-resolution PNG or SVG of the styled snippet. Includes window-chrome styling options (macOS-style title bar, drop shadows, background gradients) to make the screenshot presentation-ready.

## Why use it?

A plain screenshot of a code editor looks inconsistent and unpolished across different tools/themes; Carbon standardizes that into one clean, customizable, high-resolution export, making code snippets look intentional in slides, docs, or social posts without manual image editing.

## Basic Usage

Paste code into the editor pane, choose a theme/background/font from the toolbar, then export as PNG or SVG via the export button.

## Key Features

- Wide range of syntax themes and background gradients
- Customizable window chrome (title bar, shadows, padding)
- Export to PNG or SVG at high resolution
- Shareable link to a specific styled snippet
- Supports most common programming languages for syntax highlighting

## Top 5 Use Cases

1. Creating polished code graphics for blog posts and articles
2. Making consistent-looking code slides for a presentation
3. Sharing a code snippet on social media with clean formatting
4. Embedding a styled snippet in documentation
5. Quick visual comparison of before/after code changes as an image

## Competitors

- **Ray.so** — very similar code-screenshot tool with a different theme/style set; largely interchangeable with Carbon.
- **IDE screenshot plugins (e.g. CodeSnap for VS Code)** — in-editor convenience, but usually fewer style/export options than Carbon.

## Pros

- Fast, polished output with minimal effort
- Wide theme/customization options
- Free to use
- Shareable link support for quick collaboration

## Cons

- Manual copy-paste workflow, not scriptable/automatable
- No live code execution — presentation only
- Large snippets can get visually cramped in a single image export
