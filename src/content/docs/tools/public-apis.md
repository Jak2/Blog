# Public APIs

**[public-apis/public-apis](https://github.com/public-apis/public-apis)**

![Stars](https://img.shields.io/github/stars/public-apis/public-apis?style=flat-square) ![License](https://img.shields.io/github/license/public-apis/public-apis?style=flat-square) ![Last commit](https://img.shields.io/github/last-commit/public-apis/public-apis?style=flat-square)

## Overview

Public APIs is a collective, community-curated list of free APIs spanning nearly every domain — weather, finance, entertainment, government data, machine learning, and more — organized into browsable categories.

## What is it?

A curated README-based directory (one of GitHub's largest "awesome" lists) cataloging free/public APIs with links, auth requirements, HTTPS support, and CORS notes for each entry. Maintained through ongoing community pull requests rather than any single organization's product.

## Why use it?

Finding a reliable free API for a given data type — sports scores, currency rates, dog images, government datasets — usually means scattered web searches through dead links and undocumented services. This list centralizes that discovery with basic metadata (auth needed, HTTPS, CORS) so evaluating an option takes seconds, not a search session.

## Installation

N/A — it's a reference list, not an installable package. Browse the README by category.

## Basic Usage

Open the repo, jump to a category (Weather, Finance, Machine Learning, Games & Comics, Government, etc.), and pick an API entry — each row links directly to the provider's docs.

## Key Features

- Broad category coverage across nearly every data domain
- Per-entry metadata: auth type, HTTPS support, CORS support
- Actively maintained via community pull requests
- No cost, no install — pure reference resource

## Top 5 Use Cases

1. Finding a free data source for a side project or prototype
2. Sourcing APIs for hackathon/proof-of-concept builds
3. Discovering government/open-data APIs for research
4. Building demo apps needing real (not mocked) data quickly
5. Educational exploration of what public APIs exist in a given domain

## Competitors

- [Awesome Quant](/docs/tools/awesome-quant) — same "curated list" format, but scoped to quant finance rather than general public APIs.
- RapidAPI marketplace — searchable API marketplace with many paid tiers, vs. this list's free-only, no-platform-lock-in curation.

## Pros

- Extremely large community (472.7k+ stars, 52.2k+ forks) — the de facto standard list of its kind
- MIT licensed, zero cost to use
- Broad, genuinely diverse category coverage
- Actively maintained with high contribution volume

## Cons

- A list, not a service — entries can go stale or change terms without the list catching up instantly
- No usage/rate-limit guarantees; each linked API has its own reliability
- Sheer size makes browsing less efficient than a searchable database for narrow needs
