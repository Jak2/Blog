## Overview

Awesome Quant is a curated, community-maintained directory of libraries, packages, and resources for quantitative finance — covering numerical computing, derivatives pricing, trading systems, portfolio optimization, factor analysis, and market data across a dozen languages.

## What is it?

An "awesome list" organized into 18+ categories with hand-selected entries linking to GitHub repos and official docs, spanning Python, R, Julia, Java, JavaScript, Rust, C++, C#, Scala, Haskell, Go, and Matlab. Rather than a library itself, it's the map to the quant-finance tooling ecosystem — numerical libraries, backtesting frameworks, trading engines, risk/portfolio tools, and data sources.

## Why use it?

Quant finance tooling is scattered across many languages and niches — pricing libraries in one ecosystem, backtesting frameworks in another, data feeds elsewhere. Awesome Quant collects the maintained, credible options in one place so you're not starting a search from zero, or missing the standard tool for a given sub-problem (options pricing, factor models, market microstructure).

## Installation

N/A — it's a curated list, not an installable package. Browse the README or search it for a category.

## Basic Usage

Open the repo, jump to the relevant category (e.g. "Trading Systems," "Derivatives Pricing," "Portfolio Optimization"), and follow links to the actual libraries.

## Key Features

- 18+ categories spanning the full quant-finance tooling landscape
- Multi-language coverage: Python, R, Julia, Java, JS, Rust, C++, C#, Scala, Haskell, Go, Matlab
- Hand-curated entries with direct links, not auto-scraped
- Actively maintained via community pull requests

## Top 5 Use Cases

1. Finding a backtesting or trading-system framework for a given language
2. Locating derivatives pricing or risk-analysis libraries
3. Portfolio optimization and factor-analysis tooling discovery
4. Sourcing market/alternative data providers and connectors
5. Surveying the quant-finance open-source landscape before building in-house

## Competitors

- **[Public APIs](/docs/tools/public-apis)** — same curated-list format, but scoped to free public APIs generally rather than quant-finance tooling.

## Pros

- Very large community (29.3k+ stars, 3.9k+ forks)
- Broad, genuinely curated coverage across languages and sub-domains
- Zero cost/install — just a reference
- Actively maintained with regular contributions

## Cons

- A list, not a tool — still requires evaluating each linked project yourself
- Entries can go stale/unmaintained faster than the list itself is updated
- No hands-on comparison between similar tools in the same category
