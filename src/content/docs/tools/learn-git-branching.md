# Learn Git Branching

**[https://learngitbranching.js.org](https://learngitbranching.js.org)**

## Overview

Learn Git Branching is a free, interactive sandbox that visualizes exactly what Git commands do to the commit graph — branches, merges, rebases, and history — letting you experiment risk-free instead of guessing at what a command will do to a real repo.

## What is it?

A browser-based Git simulator with a graphical commit tree that updates live as you type real Git commands (`git commit`, `git branch`, `git rebase`, `git merge`, etc.). It includes a structured level-based curriculum (Introduction Sequence, Ramping Up, Moving Work Around, A Mixed Bag) plus a free "sandbox" mode for open experimentation.

## Why use it?

Git's mental model — especially rebasing, cherry-picking, and detached HEAD states — is hard to build without a visual. Practicing on a real repo risks real damage; this sandbox removes that risk entirely while showing the actual graph structure changing in response to each command.

## Basic Usage

Work through the guided levels for a structured path, or switch to sandbox mode and type any Git command to see its effect on the visualized commit tree immediately.

## Key Features

- Live visual commit graph responding to real Git syntax
- Structured levels covering branching, merging, rebasing, remotes
- Free sandbox mode for open-ended experimentation
- Multi-language support
- Command history and level solutions for reference

## Top 5 Use Cases

1. Building an intuitive mental model of Git's commit graph
2. Practicing rebase/merge scenarios without risking a real repo
3. Teaching Git fundamentals in a classroom or onboarding setting
4. Understanding what a specific command actually does to history before running it live
5. Debugging confusion around detached HEAD or diverged branches

## Competitors

- **Official Git documentation/Pro Git book** — authoritative and complete, but text-only, no visual feedback loop.
- **Practicing on a scratch local repo** — real Git behavior, but no visualization and real risk of a botched history if you're still learning.

## Pros

- Genuinely effective visual teaching tool for a notoriously abstract concept
- Free, no installation
- Structured curriculum plus open sandbox
- Safe to experiment with destructive-looking commands

## Cons

- Simplified simulation, not a full Git implementation — some edge-case behavior may differ from real Git
- No support for actual remote/collaborative workflows
- Level content assumes some baseline familiarity with the command line
