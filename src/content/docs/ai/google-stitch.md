# Google Stitch

## Overview

Stitch is an AI-native UI design tool from Google Labs, announced at Google I/O 2025. It generates complete interface layouts — and exportable front-end code — from text prompts, sketches, images, or voice input. It runs on Google's Gemini 2.5 models (it replaced an earlier Galileo AI foundation).

## What is it?

A web app that takes a description ("a fitness tracking app onboarding flow") and produces polished, responsive screens plus the underlying HTML/CSS. From one prompt it can generate up to five connected screens and map the user flow between them.

## Why use it?

- Skips the blank-canvas problem for designers and non-designers alike.
- Goes straight from idea to a usable UI + code, cutting the design-to-dev handoff time.
- Useful for early prototyping, pitching a concept, or scaffolding a UI before a developer refines it.

## How to Access

- Available via [Google Labs](https://labs.google) — sign in with a Google account.
- Free as of 2026, with monthly generation limits (Standard mode on Gemini 2.5 Flash: up to 350 generations/month).
- No install; entirely browser-based.

## Basic Usage

1. Sign in at Google Labs and open Stitch.
2. Enter a text prompt (or upload a sketch/image) describing the screen(s) you want.
3. Pick a model mode (fast/lightweight vs. higher-quality).
4. Review generated screens, iterate with follow-up prompts.
5. Export as HTML/CSS or push into Figma.

## Key Features

- Text, image, sketch, and voice-to-UI generation.
- Multi-screen generation with automatic flow-mapping between screens.
- HTML/CSS export.
- Figma integration.
- Choice between fast and higher-fidelity generation modes.

## Top 5 Use Cases

1. Rapid prototyping a mobile or web app concept for a pitch deck.
2. Generating a first-draft UI to hand to a developer or designer for refinement.
3. Exploring multiple design directions quickly for A/B concept testing.
4. Turning a rough sketch/wireframe into a polished mockup.
5. Bootstrapping a hackathon or side-project UI without a designer on the team.

## Competitors

- Galileo AI (Stitch's predecessor/inspiration)
- Uizard
- v0 by Vercel
- Figma AI features

## Pros

- Fast — usable screens in seconds.
- Free tier is generous enough for prototyping.
- Direct code export removes a manual translation step.
- Figma integration keeps it compatible with existing design workflows.

## Cons

- Generation limits on the free tier.
- Output still typically needs a developer/designer pass for production polish.
- As a Labs product it's experimental — features and limits can change without notice.
